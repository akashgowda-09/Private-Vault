# Private Vault

Private Vault is a secure web-based file management application developed using Python Flask, HTML, CSS, and JavaScript. The system allows users to upload, store, organize, and access personal files through an intuitive and user-friendly interface.

## Features

- Secure file upload and storage
- User-friendly web interface
- File organization and management
- Fast file access and retrieval
- Responsive design
- Flask-based backend architecture

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript

## Installation

1. Clone the repository

```bash
git clone https://github.com/akashgowda-09/Private-Vault.git
```

2. Navigate to the project directory

```bash
cd Private-Vault
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```text
http://127.0.0.1:5000
```
